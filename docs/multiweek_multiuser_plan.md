# 한 PC의 여러 교사 관리 + 주차 교체 + 교체 표시 개선 계획서

작성일: 2026-09-28
상태: 한 PC의 여러 교사 관리로 범위 확정 — 상세 설계는 검토 중, 구현 미착수

후속 작업은 [코드 구현 계획](daily_timetable_implementation_plan.md)과 [AI 인수인계](daily_timetable_handoff.md)를 따른다.

## 0. 최신 결정과 문서 적용 기준

사용자는 한 PC에서 여러 교사의 시간표를 관리하는 방식으로 진행하기로 확정했다.

* 한 앱에서 교사를 선택해 작업하며, 같은 시간표의 실제 수업 배치와 교체 결과를 공통으로 관리한다.
* 로그인 계정, 서버, 여러 PC의 동시 수정·동기화는 이번 구현 범위에서 제외한다.
* 학기 전체 날짜별 생성·저장을 기본 방향으로 한다. 초기 기본값은 1학기 3/1~7/31, 2학기 8/1~다음 해 1/31이며, 준비 > 기타 설정에서 날짜를 수정하고 반영 버튼으로 적용한다.
* 로컬 SQLite를 저장소 계획으로 삼는다. 사용할 패키지와 배포 세부사항은 구현 전에 확인한다.
* 수업에는 고유 ID를 부여한다. 셀 주소는 시간표 ID·날짜·교사 ID·교시로 구분하며 사용자 계정을 포함하지 않는다.
* 사용자별·주별로 저장 파일을 분리하지 않는다. 날짜별 배치와 교체 이력을 함께 저장한다.
* 저장·조회 코드를 화면에서 분리해 향후 서버 연결 가능성을 남기되, 서버 기능을 미리 구현하지 않는다.
* 현재는 문서만 수정한다. 코드 구현은 시작하지 않는다.

상세 기본 계획은 [학기 전체 날짜별 시간표 전환 계획](daily_semester_timetable_plan.md)을 따른다.
아래 §3의 주간 원본+변경분 구조와 사용자 포함 키·주별 파일안은 **과거 대안으로 보존하며 채택하지 않는다.**
§4~§7의 표시 방식과 작업 순서는 검토용 초안이다. 날짜 없이 교체 확정,
주 이동 시 재검증 생략, 다른 주에 연결된 교체 숨김 등의 제안은 확정된 구현 지침이 아니다.
날짜별 조회·검증 원칙에 맞춰 후속 설계에서 정리한다.

## 1. 배경

* 현재 원본 시간표와 이동 좌표는 요일·교시 기준이다. 결강일·보강일·선택 주는 이미 있으나 실제 날짜별 수업 이동과 표시 연결이 불완전하다.
* 문제 3가지:
  1. 여러 교사 관리 - 로그인 사용자 구분 없이 같은 시간표의 교사들을 선택해 공통 배치와 이력을 관리해야 함
  2. 다른 주와 교체 불가 - `TimeSlot(day, period)`만 있고 `date` 없음
  3. 교체 표시 꼬임 - `교사_요일_교시` 키 중복, 헤더 미갱신

## 2. 목표

* 한 PC에서 여러 교사를 관리해도 같은 수업의 배치와 교체 결과가 일관되게
* 이번주 ↔ 다음주 교체 가능하게
* 교체된 시간표가 어느 주 것인지 명확하게

## 3. 과거 저장 구조 대안 (미채택 — §0 결정 우선)

전면 교체 아님. 기존에 3개 필드 추가.

```
1층 밑판: 주단위 기본 시간표 1개 (엑셀 원본 그대로)
2층 달력: 학기 시작~끝, 휴일, 행사주
3층 스티커: 바뀐 칸만 저장 (날짜+교사+교시+누가)
```

* 셀 키 변경: `교사_요일_교시` → `교사_날짜_요일_교시_사용자`
* 예: `김선생_월_1` → `김선생_2026-09-28_월_1_userA`
* `ExchangeNode.nodeId`에 `date` 포함 (현재는 제외됨)
* 파일 나누기: `기본표.json` 1개 + `변경분_9월1주.json` 여러 개

하지 말 것:
* 20주치 통째 복사 (파일 20배, 엑셀 재업로드 시 20장 수정)

## 4. 주차 표시 스위치

위치: 시간표 상단 `[11월1주] 월(9/28)~금(10/2)` 영역

* 스위치 OFF (교체 화면 기본): `월,화,수,목,금`만 표시, 날짜 없음
* 스위치 ON (계획서/개인시간표 기본): `월(9/28)`처럼 날짜 표시
* 라벨과 날짜는 같은 `weekMonday`에서 계산 (현재 `11월인데 9/28` 버그 수정)

신규 Provider: `showWeekHeaderProvider: bool`

## 5. 화살표/하이라이트/외곽선 표시 방법 (전체 시간표 기준)

우선순위 공통: `선택 > 교체됨(확정) > 선택된 경로 > 교체가능 후보 > 교사 하이라이트`

### 5-1. 표시 ON (날짜 있음, 확정본) - `[11월1주] 월(9/28)~금(10/2)`
* 하이라이트(선택): 고른 칸 굵은 실선 + 위 헤더 `월(9/28)`도 같이 진하게
* 외곽선(교체됨): 실선 굵게, 2종류만
  * 원본(빌려준 칸) = 빨간 X + 빨간 테두리
  * 목적지(들어온 칸) = 파란 ○ + 파란 테두리
* 화살표: 실선 진하게, 지금 보고 있는 주(`currentWeekMonday`)에 속한 것만 표시, 다른 주는 숨김
* 헤더: 오른쪽에 `2026.11.02-11.06 · 교체 N건` 표시

### 5-2. 미표시 OFF (날짜 없음, 밑그림) - `월,화,수,목,금`
* 하이라이트(선택): 고른 칸 1개만 진한 테두리, 교사 이름줄 연하게
* 외곽선(후보): 배경색 + 얇은 점선 (임시 의미)
  * 초록 배경 = 1:1 가능
  * 노랑 배경 = 순환/2중 필요
  * 회색 = 불가
* 화살표: 선택한 경로 1개만 점선 + 반투명 + 숫자 `1,2` 배지, 확정 표시(X,○) 숨김

### 5-3. OFF 모드 날짜 오버레이 (UI 변형 없음)
* 헤더/컬럼 변경 없이 셀 우측 상단에 `12.11` 꼬리표만 표시
* 구현: `SimplifiedTimetableCell.build` + `ExchangedCellStatusOverlay` 층에
  `Stack/Positioned(top:2, right:2, fontSize:9)` 추가, `DataGrid` 재생성 없음
* 날짜 여러 개 겹치면 `+2`로 개수 표시, 클릭 시 목록 표시
* X/○ 심볼과 겹치지 않게 구석 배치

### 5-4. 교체됨 구분 표시 (X/○ + 꼬리표)
* 현재 구조(`SimplifiedTimetableCell: Stack 3층`) 그대로 사용:
  `내용 + CellStatusBorderOverlay + ExchangedCellStatusOverlay`
* 원본(빠진 수업) = X + 빨간 테두리, 목적지(맡은 수업) = ○ + 파란 테두리
* 문제점: 키가 `교사_요일_교시`라 타주와 겹치고, 확정분이 전체에 다 켜짐
* 개선: 셀에 `overlayDate: '12.11'` 필드 1개 추가, 날짜 꼬리표로 구분
* 툴팁에 날짜 목록 표시 (`CellStatusTooltips.forCellState` 확장)

### 5-5. ON/OFF 표시 분기 (구현 기준)
* 분기 위치: `TimetableDataSource._createDataCellState`에서 `showWeekHeader` 1개로 분기
* OFF: 교체됨 X/○ OFF + 날짜 꼬리표 ON + 경로 점선 1개(선택 경로만)
* ON: 해당 주(`currentWeekMonday`) 키만 X/○ + 굵은 실선 + 실선 화살표, 타주는 숨김
* ON에서는 날짜 꼬리표 OFF (헤더에 이미 날짜 있음)

## 6. 작업 순서 (확정 필요)

1. 교체 화면: 주차 표시 없이 템플릿 경로만 찾기 (`day_period` 기준)
2. 계획서에서 날짜 지정되면: 주차 표시 ON + 해당 주에만 화살표/외곽선 표시
3. 주 이동(`moveToWeek`) 시 필터만 갈아끼움, 로직 재계산 없음
