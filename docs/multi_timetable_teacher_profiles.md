# 시간표 다중화 & 교사별 계획서(인쇄 프로파일) 설계

> 작성일: 2026-08-26
> 최종 수정: 2026-08-26 (UI 개편 구현 반영)
> 상태: 구현 완료 (반영 결과는 §8)

## 1. 요구사항

### 기존 (단일 구조)
- 시간표: 학교 1개당 1개만 등록 가능
- 인쇄 프로파일: 양식 2개 하드코딩(`pdf_export_settings_template_{0|1}.json`), 교체 건과 무관하게 전역 1세트

### 신규 요구사항
1. **시간표(학기) 다중 등록**: 이름을 부여한 여러 시간표를 등록하고 목록에서 전환
2. **시간표별 데이터 완전 분리**: 교체 목록, 결보강 데이터, 인쇄 프로파일은 시간표별로 독립
3. **교사별 계획서(인쇄 프로파일) 관리**: 시간표 안에서 교사 이름별로 계획서를 여러 개 관리

```
월계중1학기 (시간표/학기)
└── 홍길동 (교사)
    ├── 계획서1
    ├── 계획서2
    └── 계획서3
└── 김철수 (교사)
    └── 계획서1
```

4. **교체불가 공유**: 같은 시간표 안에서는 **교사가 달라도** "교체 불가" 셀을 공유
   - 교체불가 셀은 `시간표` 단위로 1세트만 존재 (모든 교사가 공유)
   - 계획서와도 무관하며, 교사 전환과도 무관
5. **일괄 출력**: 교체 목록에서 여러 건을 선택해 각 건에 지정된 계획서로 한 번에 PDF 출력
6. **교체 상태 공유**: 같은 시간표 안에서 교체 결과(누적 교체 상태)는 모든 교사·계획서가 공유
   - 교체 1건이 실행되면 그 결과는 시간표 전체에 반영됨 (교사별로 분기되지 않음)
   - 다른 교사를 교체할 때도 이전 교체가 반영된 **현재 시간표 상태**를 기준으로 검증
   - 계획서는 인쇄 설정일 뿐, 교체 상태를 복제·분기하지 않음

### 확정된 방식 (사용자 답변)
| 항목 | 결정 |
|---|---|
| 시간표 구분/전환 | 이름 부여 + 목록 전환 |
| 시간표 전환 시 교체 목록 | 시간표별 완전 분리 |
| 인쇄 프로파일 | 이름 있는 계획서 + 교사별 관리 + 교체 건에 지정 |
| 출력 단위 | 여러 건 일괄 출력 |
| 교체 건 식별자 | `ExchangeHistoryItem.id` 사용 (파생 exchangeId 금지 — 내용 기반이라 충돌 위험) |
| 시간표 테마 | v1에서 전역 유지 (추후 확장) |

### 교사·학교명을 시간표 속성으로 옮기는 이유

기존에는 교사명·학교명이 앱 전역 설정에 **자유 입력 문자열**로 저장됐다. 계층 정의상
교사는 시간표에 종속되는데 저장 위치가 계층과 어긋나 다음 문제가 생긴다.

- 시간표를 전환해도 교사명이 그대로 남아, 다른 학교 시간표에 이전 학교 교사명이 붙는다
- 오타가 나면 교체 화면 행 하이라이트·개인 시간표·계획서 교사명이 **조용히 동시에** 빗나간다
  (엑셀 교사 목록이라는 정답지가 있는데 자유 입력을 받고 있었다)
- 시간표는 사실상 "학교 + 학기" 단위(`월계중2학기`)이므로 학교명도 시간표 속성이다

⇒ 두 값을 `TimetableRegistryEntry`로 옮기고, **교사는 드롭다운(엑셀 교사 목록)으로만**
   선택하게 해 존재하지 않는 교사를 고를 수 없게 만든다.

**소비처 3곳**을 전역 설정 대신 활성 엔트리에서 읽도록 바꾼다.

| 소비처 | 위치 | 용도 |
|---|---|---|
| 교체 화면 행 하이라이트 | `exchange_screen.dart` | 내 시간표 행 강조 |
| 개인 시간표 기본 교사 | `personal_schedule_screen.dart` | 초기 표시 교사 |
| 계획서 교사명 자동 입력 | `substitution_output_widget.dart` | PDF 교사명·학교명 |

개인 시간표 화면은 `teacherName`을 **기본값으로만** 쓰고, 거기서 다른 교사를 골라도
`teacherName`을 덮어쓰지 않는다 — 남의 시간표를 잠깐 보는 것이 그 화면의 용도다.

- ID 규칙
  - 시간표: `tt_{yyyyMMdd_HHmmss}`
  - 계획서: `pp_{yyyyMMdd_HHmmss_microsecond_seq}` — 같은 초에 연속 생성해도 충돌하지 않도록
    마이크로초와 프로세스 내 시퀀스를 포함한다. ID는 절대 재사용하지 않는다
    (삭제된 계획서를 가리키는 `profileId`가 새 계획서에 잘못 붙는 것을 원천 차단).
- 계획서는 평면 리스트에 `teacherName` 필드로 교사 귀속 → UI에서 교사별 그룹핑
- **이름 중복 정책**
  - 계획서 이름: 같은 교사 안에서 중복 가능하나 저장 전 경고 (권장: 고유 이름)
  - 시간표 이름: 중복 가능하나 등록·이름 변경 시 경고
    ("같은 이름의 시간표가 이미 있습니다. 목록에서 구분이 어려워집니다.")
    — 전환·삭제 다이얼로그가 이름만으로 대상을 지칭하므로 중복은 오조작 위험이 크다.

### ② 시작 화면 (`start_content_screen`) — 시간표 카드가 계층의 루트

기존 홈은 시간표 배너와 **무관한 전역 '기본 정보'(교사명·학교명) 카드**가 평평하게
나열돼 있어 계층이 드러나지 않았다. 아래처럼 교사·학교명·계획서를 시간표 카드
**안쪽**으로 넣어, 들여쓰기가 곧 종속 관계를 나타내게 한다.

**A. 기본 상태**

```
┌────────────────────────────────────────────────────────────────────┐
│  🗓  월계중2학기                                       [ 전환 ▼ ]  │
│      2학기 전체시간표 확정(0820).xlsx · 교사 43명 · 8/20 등록      │
│                                                                    │
│  ┌──────────────────────────────────────────────────────────────┐  │
│  │ 👤 교사      [ 정원길                             ▼ ]        │  │
│  │              이 시간표의 교사 목록에서 선택                  │  │
│  │                                                              │  │
│  │ 🏫 학교명    [ 월계중학교                            ]       │  │
│  │              계획서 인쇄에 사용됩니다                        │  │
│  │                                                              │  │
│  │ 📄 계획서     계획서1 · 계획서2                   [ 관리 > ] │  │
│  └──────────────────────────────────────────────────────────────┘  │
│                                                                    │
│                            [ ＋ 시간표 추가 ]   [ 시간표 관리 > ]  │
└────────────────────────────────────────────────────────────────────┘
```

- **교사는 반드시 드롭다운**(그 시간표의 엑셀 교사 목록). 자유 입력을 없애면
  오타로 하이라이트가 빗나가는 문제가 구조적으로 사라진다
- **[저장] 버튼 제거** — 교사는 선택 즉시 확정, 학교명은 포커스 이탈 시 자동 저장
  (기존처럼 저장을 눌러야 반영되는 구조는 잊기 쉽다)
- 기존 `기본 정보` 카드는 제거하고 이 카드에 흡수한다

**B. 전환 드롭다운 (진입점 통합)**

```
┌────────────────────────────────────────────────────────────────────┐
│  🗓  월계중2학기                                       [ 전환 ▼ ]  │

```

- 각 행에 그 시간표의 **교사 · 계획서 수 · 교체 건수**를 함께 표시한다
  → 전환하면 무엇이 따라오는지 고르기 전에 알 수 있다
- 기존 `[변경 >]` 링크와 `[시간표 변경/추가]` 버튼은 **이 드롭다운으로 통합해 제거**한다
  (같은 관리 화면으로 가는 진입점이 3개나 중복돼 있었다)

**C. 시간표 미등록**

```

│                                                                    │
```

교사·학교명·계획서 영역은 **아예 그리지 않는다.** 시간표가 없으면 교사 목록 자체가
존재하지 않으므로, 빈 입력란을 보여주는 것은 거짓 정보다.

계획서 줄은 교사를 고르기 전까지 비활성(회색)으로 둔다 — 계획서는 교사에 귀속되므로
교사 없이 만들 수 없다.

### ③ 계획서 출력 — 결보강 출력 탭 (교사별 계획서 바)

```
┌────────────────────────────────────────────────────────────────┐
│ 👤 교사   [ 정원길 (시간표에 설정된 교사)        ▼ ]             │
│           │ 클릭 시 펼침 (교사 수가 많아 검색 입력 지원):        │
│           │  ┌───────────────────────┐                        │
│           │  │ [🔍 이름 검색…       ] │                        │
│           │  │ ✓ 정원길         · 2  │ ← 현재 선택 / 계획서 수  │
│           │  │   김철수         · 0  │ ← 0이면 계획서 없음      │
│           │  │   이영희         · 1  │                        │
│           │  └───────────────────────┘  (엑셀 파싱, 가나다순)  │
│ 📄 계획서 [ 계획서1 ●                          ▼ ]  [＋][✎][🗑] │
│           │ 선택 교사의 계획서만 표시 + 맨 위에 '미지정' 항목     │
│           │ ● = 저장하지 않은 변경 있음                          │
├────────────────────────────────────────────────────────────────┤
│ (계획서가 없는 교사를 선택한 경우)                               │
│ ⓘ '김철수'의 계획서가 없습니다.  [＋ 새로 만들기]                │
├────────────────────────────────────────────────────────────────┤
│ 양식 [양식 1 ▼]  폰트 [한바탕 ▼]  크기 [10.0]  비고 [해제]        │
│ 교사명 [정원길] 학교명 [월계중학교]  ← 시간표 설정에서 자동 채움  │
│ 결강기간 · 입력란 (기존과 동일)                                  │
├────────────────────────────────────────────────────────────────┤
│ [PDF 미리보기]   [이 계획서에 저장 ('계획서1')]                   │
└────────────────────────────────────────────────────────────────┘

  [기본 규칙]
  - 교사 목록 출처: 현재 활성 시간표의 교사 목록 (TimetableData.teachers,
    엑셀 파싱 결과, 가나다순 정렬) — 별도 등록/삭제 없음
  - **기본 선택은 시간표에 설정된 교사(`teacherName`)**. 다른 교사의 계획서를
    만들 때만 바꾼다. 여기서 다른 교사를 골라도 `teacherName`은 덮어쓰지 않는다
    (탭 안에서만 유효한 국소 전환. §3⑥과 동일 원칙)
  - 교사명·학교명 입력란은 활성 시간표의 `teacherName`·`schoolName`으로 자동
    채워진다 → 사용자가 매번 타이핑할 일이 없다
  - 교사 드롭다운은 **검색 입력을 지원**하고 항목마다 **계획서 개수를 표시**한다
    (중학교 기준 교사 50~80명. 단순 스크롤 목록이면 하나씩 눌러봐야
     계획서 유무를 알 수 있어 탐색 비용이 크다)
  - 계획서 드롭다운: 선택한 교사의 계획서 목록 + 맨 위 '미지정 (양식 설정 사용)' 항목
    → 계획서를 고른 뒤에도 언제든 미지정으로 되돌릴 수 있어야 한다(§4④와 동일 규칙)
  - 교사 전환 → 계획서 목록만 갱신 (교체불가·교체 상태는 시간표 단위 공유라 변화 없음)
  - 계획서 없는 교사 → 안내 메시지 + [새로 만들기] 진입 유도
  - [＋ 새로 만들기] → 현재 화면 값을 복사한 새 계획서 생성 + 이름 입력
    (기본 이름 `계획서{n+1}`. 교사 미선택 상태면 "교사를 먼저 선택하세요" 안내)
  - [✎ 이름변경] / [🗑 삭제]는 계획서가 선택된 경우에만 활성화
  - 관리 버튼은 아이콘 전용이며 각각 툴팁('새로 만들기'/'이름 변경'/'삭제')을 갖는다

  [미저장 변경 보호 — 필수]
  계획서 설정은 [이 계획서에 저장]을 눌러야 기록된다. 따라서:
  - 화면 값이 선택 계획서와 달라지면 계획서 이름 옆에 ● 표시(dirty)
  - dirty 상태에서 **교사 전환 / 계획서 전환 / 탭 이탈 / 시간표 전환**을 시도하면
    확인 다이얼로그를 띄운다
      ┌──────────────────────────────────────┐
      │ 저장하지 않은 변경이 있습니다        │
      │ '계획서1'의 변경 내용을 저장할까요?  │
      │      [취소]  [저장 안 함]  [저장]    │
      └──────────────────────────────────────┘
  - 확인 없이 덮어쓰면 폰트·크기·비고·학교명 편집이 조용히 사라진다
    (계획서를 여러 개 두는 기능 특성상 드롭다운 왕복이 잦아 반드시 재현됨)

  [삭제 후 선택 규칙 — 필수]
  - [🗑 삭제] → 확인 다이얼로그("이 계획서가 지정된 교체 건은 미지정 상태가 됩니다")
  - 삭제 성공 후 **같은 교사의 남은 계획서 중 첫 번째를 자동 선택**한다
  - 남은 계획서가 없으면 미지정 + "'○○'의 계획서가 없습니다" 안내를 표시한다
  - 무선택(빈 화면) 상태로 두지 않는다 — 안내도 저장 버튼도 없는 사각지대가 생긴다
  - 삭제된 계획서를 가리키던 교체 건의 `profileId`는 **조회 시 미지정으로 처리**한다
    (레코드에서 즉시 제거하지는 않음. 계획서 ID는 재사용되지 않으므로 안전)
```

### ④ 계획서 출력 — 내용 입력 탭 (일괄 출력)

```
┌────────────────────────────────────────────────────────────────┐
│ 교체 목록            [2건 일괄 출력]  [전체선택] [선택해제]       │
├───┬───────┬─────────┬────────────┬─────────────┬──────────────┤
│ ☑ │ 교사   │ 결강일   │ 결강 교시   │ 계획서       │ 출력          │
├───┼───────┼─────────┼────────────┼─────────────┼──────────────┤
│ ☑ │ 홍길동 │ 8/27(목) │ 3교시 수학  │ [계획서1  ▼]  │ ✓ 08-26 출력 │
│ ☑ │ 홍길동 │ 8/28(금) │ 5교시 국어  │ [계획서2  ▼]  │              │
│ ☐ │ 김철수 │ 8/31(월) │ 2교시 음악  │ [미지정    ▼] │              │
└───┴───────┴─────────┴────────────┴─────────────┴──────────────┘
     ↑ 행별 드롭다운에는 "그 행 교사"의 계획서만 표시
       + '미지정' 항목 + 맨 아래 '＋ 새 계획서…' 항목

  [행별 계획서 드롭다운]
  - 항목 구성: 미지정 / 그 행 교사의 계획서들 / ＋ 새 계획서…
  - **'＋ 새 계획서…'는 필수**. 계획서가 0개인 교사 행에서 이 항목이 없으면
    결보강 출력 탭 이동 → 교사 선택 → 생성 → 다시 돌아오기를 건수만큼 반복해야 한다.
    선택 시 그 자리에서 이름 입력 다이얼로그 → 생성 → 그 행에 즉시 지정
  - 선택 즉시 `ExchangeHistoryItem.profileId`에 저장(별도 저장 버튼 없음)

  [일괄 출력 버튼]
  - 라벨은 선택 건수를 반영: `2건 일괄 출력`
  - **선택 0건이면 버튼을 비활성화**한다(누른 뒤 에러 스낵바를 띄우지 않는다)
  - 삭제된 교체 건이 선택 집합에 남아 있으면 카운트에서 제외한다

  [출력 흐름]
  [일괄 출력] → 저장 폴더 1회 선택 → 진행 다이얼로그 → 완료 요약
  ┌──────────────────────────────────────┐
  │ 일괄 출력 중…            2 / 5       │
  │ ▓▓▓▓▓▓▓▓░░░░░░░░░░░                  │
  │ 홍길동_0828_5교시국어.pdf            │
  │                        [취소]        │
  └──────────────────────────────────────┘
  - 건당 수 초가 걸릴 수 있어 **진행률과 취소가 필요**하다.
    스낵바 하나만 띄우고 블로킹하면 10건 이상에서 멈춘 것처럼 보인다
  - [취소] → 진행 중인 1건까지만 마치고 중단, 요약에 "취소됨 n건" 표시
  → 완료 다이얼로그: "5건 중 4건 출력 성공, 1건 실패" (실패 시 건별 사유 표시)

  [자동 파일명 규칙]
  기본형: {교사명}_{결강일}_{교시과목}.pdf     예) 홍길동_0827_3교시수학.pdf
  - 값은 **그 교체 건의 첫 행** 기준으로 만든다
  - 한 건이 여러 행(다교시·다일자)이면 대표성이 없으므로 범위·건수를 덧붙인다
      여러 날짜: 홍길동_0827-0828_3교시수학외4건.pdf
      같은 날 여러 교시: 홍길동_0827_3교시수학외2건.pdf
  - 파일명 금지 문자(`< > : " / \ | ? *`·공백)는 `_`로 치환
  - 중복 시 `_2`, `_3` 접미사 — **실행 내 중복과 디스크 기존 파일을 모두 회피**한다
    (덮어쓰기 방지). 단, 접미사만으로는 내용 구분이 안 되므로 위 범위 표기를 우선한다
```

### ⑤ 교체불가 셀 (시간표 단위 공유 규칙)

```
교체 화면의 교체불가 셀 지정 (셀 우클릭 등)
  → 저장 위치: non_exchangeable_data_{시간표hash}.json
  → 단위: 시간표 1세트 (교사 키 없음 — 모든 교사가 공유!)

  월계중1학기
  └── 교체불가 셀 1세트 ──┬── 홍길동에게도 적용
                          ├── 김철수에게도 적용
                          ├── 모든 교사에게 적용 (교사 무관)
                          └── 계획서1/2/3 공통 (계획서 무관)

  ⇒ 어떤 교사 화면에서 교체불가를 지정해도 시간표 전체에 반영
  ⇒ 계획서를 새로 만들어도 교체불가 설정이 복사/초기화되지 않음
  ⇒ 시간표를 전환하면 해당 시간표의 교체불가 데이터가 로드됨 (시간표 간 독립)
```

### ⑥ 교사 전환 (관리 방식)

```
학교(시간표) 전환 = 전역 전환 (시간표 관리 화면, 앱 전체 데이터 교체)
교사 전환        = 화면 국소 전환 (계획서 출력 탭 안에서만 수행)

┌──────────────────────────────────────────────────────┐
│ 계획서 출력 탭                                        │
│ 교사: [홍길동 ▼] ← 드롭다운 선택으로 전환              │
│        │                                             │
│        ├─ 1. 계획서 목록 → '홍길동'의 계획서로 교체     │
│        │     (계획서 없으면 "새로 만들기" 안내)         │
│        ├─ 2. 교체불가 셀   → 변화 없음 (시간표 공유)    │
│        ├─ 3. 교체 목록     → 변화 없음 (시간표 공유)    │
│        └─ 4. 마지막 선택 교사 저장 → 재시작 시 복원      │
│                                                      │
│ 교사 목록 출처: 현재 활성 시간표의 교사 목록            │
│   (ExcelService가 파싱한 TimetableData.teachers)      │
│ 교사 추가/삭제: 불가 (엑셀 원본에 있는 교사만 존재)      │
└──────────────────────────────────────────────────────┘

저장 구조 (print_profiles_{timetableId}.json):
  { "profiles": [...],
    "lastSelectedTeacher": "홍길동",     ← 교사 전환 시 갱신
    "lastUsedProfileId": "pp_..." }     ← 교사별 마지막 계획서 복원용

다른 화면의 교사 선택과의 관계:
  - 교체 관리 화면: 시간표 전체 그리드 표시 (교사 전환 개념 없음)
  - 개인 시간표 화면: 자체 교사 선택 UI 유지 (기존과 동일, 독립 동작)
```

## 6. 리스크 및 유의사항

1. **두 교체 식별자 공존**: `ExchangeHistoryItem.id`(안정) vs 파생 `exchangeId`(내용 기반, 재교체 시 충돌 가능) — 계획서 지정 키는 반드시 `item.id` 사용
2. **마이그레이션 없음**: 구 단일 구조 데이터의 자동 이전은 제공하지 않음 — 기존 시간표는 관리 화면에서 다시 등록
3. **교체불가 공유 보장**: 계획서 복제/생성 로직에서 교체불가 데이터를 건드리지 않도록 저장 계층 분리 유지
4. **스코프 필수 정책**: 교체 목록·결보강·교체불가 저장/로드는 시간표 스코프가 없으면 건너뛰며, 레거시 전역 파일로 폴백하지 않음
5. **미저장 변경 유실**: 계획서 설정은 수동 저장이므로 드롭다운 전환이 곧 덮어쓰기가 된다 — dirty 표시 + 전환 시 확인이 없으면 편집 내용이 조용히 사라짐 (§3③)
6. **파괴적 초기화의 무확인 실행**: 동일 경로 파일 재선택 시의 교체 목록 정리는 사용자 눈에 "같은 파일을 다시 골랐을 뿐"으로 보인다 — 반드시 사전 확인 (§3①)
7. **미지정 폴백 대상**: 절대 `lastUsedProfileId`(교사 무관 전역값)를 쓰지 않는다 — 다른 교사 이름이 찍힌 PDF가 나옴 (§4)
8. **다행 교체 건의 파일명**: 첫 행만으로 이름을 만들면 다교시·다일자 건이 서로 구분되지 않는다 — 범위·건수 표기 필요 (§3④)
9. **전역 교사명 잔존 금지**: `defaultTeacherName`/`defaultSchoolName`을 읽는 코드가 한 곳이라도 남으면 진실원본이 둘이 되어 시간표별 값과 어긋난다 — 소비처 3곳을 모두 옮기고 저장·읽기 코드를 함께 제거할 것 (§2)
10. **교사 선택의 국소성**: 결보강 출력 탭·개인 시간표 화면에서 다른 교사를 골라도 `teacherName`을 덮어쓰지 않는다 — 남의 시간표 열람이 내 설정을 바꾸면 안 된다

## 7. 검증 결과 보완 사항 (점검 확정 동작)

1. **교체불가 해시**: 레지스트리 활성 시간표 해시 기준 (전환 대응)
2. **동일 파일 재선택**: 관리 화면에서 동일 경로 파일을 다시 선택하면 **새 항목을 만들지 않고 기존 항목을 갱신**한다. 내용(contentHash)이 바뀐 경우에만 해당 시간표의 교체 목록·결보강 스코프 데이터를 정리하며(계획서는 유지), **정리 전에 삭제 대상 건수를 명시한 확인 다이얼로그를 띄우고 [취소] 시 아무것도 변경하지 않는다**(§3①).
3. **홈 우회 차단**: 홈의 파일 선택 버튼은 시간표 관리 화면으로 연결 (스코프 불일치 방지). '해제' 버튼 제거 — 시간표를 비활성으로 되돌리는 수단은 제공하지 않으며, 더 쓰지 않는 시간표는 **삭제**로 정리한다.
4. **고스트 데이터 차단**: 활성 시간표가 없으면(전체 삭제) 어떤 파일도 로드하지 않고 메모리만 초기화. 활성 시간표를 삭제한 경우에는 남은 시간표 중 첫 번째로 자동 전환하고, 그 사실을 삭제 다이얼로그에 미리 고지한다.
5. **전환 시 정리**: undo/redo 스택 초기화 + 교체 화면 UI 상태 리셋 선행
6. **계획서 미지정 해제**: 내용 입력 그리드와 **결보강 출력 탭의 계획서 드롭다운 양쪽 모두** '미지정' 항목을 제공해 지정 해제가 가능해야 한다 (한쪽에만 있으면 되돌릴 방법이 없어짐)
7. **일괄 출력 안전장치**: 양식 인덱스 범위 검증, 사용자 지정 템플릿 파일 존재 확인, 출력 파일명이 실행 내 중복 + 디스크 기존 파일 모두 회피 (덮어쓰기 방지)
8. **레거시 폴백 제거**: 구 단일 메타데이터·전역 파일 참조 코드 전면 제거 (마이그레이션 불필요 정책 반영). 단 `pdf_export_settings_template_{0|1}.json`은 **계획서 미지정 건의 인쇄 설정 폴백**으로 계속 사용하므로 제거 대상이 아니다.

### 사양과 다르게 구현한 부분

1. **교사 드롭다운 검색 미구현** — §3③은 검색 입력을 규정했으나, 계획서 개수 뱃지만 넣었다.
   드롭다운 항목이 곧 교사 목록(수십 명)이라 검색이 유용하지만, Flutter `DropdownButton`에
   검색을 넣으려면 `DropdownMenu`로 교체해야 해 범위를 키운다. 뱃지만으로도 "계획서 없는 교사를
   눌러봐야 아는" 문제는 해소되므로 후순위로 남긴다.
2. **시간표 전환 드롭다운 검색 미구현** — 등록되는 시간표는 학기당 1개 수준(보통 2~5개)이라
   검색이 필요한 규모가 아니다. 6개를 넘으면 추가한다.
3. **결보강 "행 수"를 "입력 건수"로 표기** — `SubstitutionPlanState`는 행 목록이 아니라
   저장된 날짜·보강 과목 맵이라 행 수를 셀 수 없다. `결보강 입력 N건`으로 표기한다.

### 변수명 규칙

- `TimetableRegistryEntry.teacherName` — 이 시간표를 쓰는 사용자 본인의 교사
- `PrintProfile.teacherName` — 계획서가 귀속된 교사

이름은 같지만 의미가 다르므로 모델 주석에 명시했다. UI 라벨은 양쪽 모두 **「교사」**로 통일한다
(소유격 "내 ~"는 쓰지 않는다).

### 점검했고 문제 없던 항목

- **§7-2 갱신 취소 복구**: `reloadActive()` → `timetableSwitchVersionProvider` 증가 →
  `start_screen`의 리스너가 `resetAllStates` 후 저장 데이터 재로드. 관리 화면이 위에 push된
  상태에서도 `start_screen`이 살아 있어 리스너가 동작함
- **§7-4 고스트 데이터 차단**: `_loadSavedData()`가 `activeEntry != null`을 확인한 뒤에만
  파일을 읽음
- **§7-5 전환 시 정리**: 전환 리스너가 `stateResetProvider.resetAllStates()`를 선행 호출
- **교체불가 데이터**: 시간표 삭제 시 `non_exchangeable_data_{hash}.json`을 지우지 않는 것이
  맞음 — 해시가 같은(내용이 같은) 다른 시간표가 공유할 수 있기 때문
- **교사 자동 추정 순서**: `selectExcelFile()` 이후 교사 목록이 새 파일 기준으로 갱신되고,
  레지스트리에는 아직 새 항목이 없으므로 `activeEntry`가 "직전 시간표"로 올바르게 잡힘
