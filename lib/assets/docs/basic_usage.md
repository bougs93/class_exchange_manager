# 기본 사용법

> 💡 **유튜브 영상 가이드**: 프로그램 사용법 영상은 아래 링크를 클릭하여 확인하실 수 있습니다.
>
> [프로그램 사용법 영상 보기](https://youtu.be/tYVXq3_XRFs)

## 메뉴 구성

상단 메뉴는 **시작 · 교체 · 계획서 출력 · 안내 · 시간표 · 도움말** 순서입니다.

| 메뉴 | 설명 |
| ------ | ------ |
| **시작** | 엑셀 시간표 불러오기, 교사명·학교명 등 기본 정보·설정 |
| **교체** | 시간표 교체 작업 (1:1·2중·순환·보강 등) |
| **계획서 출력** | 결보강 내용 입력, PDF 계획서 출력 |
| **안내** | 교사·학급 안내 문구 자동 생성 |
| **시간표** | 관련 교사들의 개인 시간표 카드 보기 |
| **도움말** | 프로그램 정보, 기본 사용법, PDF 양식 제작 |

---

## 시작하기

1. **시작** 메뉴에서 **엑셀 파일 선택**을 클릭하여 학교 시간표 파일(`.xlsx`, `.xls`, `.xlsm`)을 불러옵니다.
2. **교사명·학교명**을 입력하고 저장합니다. (계획서 출력·시간표 화면에서 기본값으로 사용됩니다.)
3. **교체** 메뉴로 이동하여 교체 모드를 선택하고 작업을 진행합니다.
4. 교체가 끝나면 **계획서 출력 > 내용 입력**에서 결강일·교체일 등을 지정한 뒤 **결보강 출력**에서 PDF를 저장합니다.

---

## 시작 — 기본 정보·설정

### 엑셀 파일

- 시간표가 들어 있는 엑셀 파일을 선택합니다.
- 파일을 바꾸면 저장된 교체·날짜 데이터 초기화 여부를 묻는 안내가 표시될 수 있습니다.

### 기본 정보

- **교사명**, **학교명**을 저장해 두면 문서 화면 등에 자동으로 채워집니다.

### 설정 (시작 하단 카드)

| 항목 | 설명 |
| ------ | ------ |
| **2중 교체** | 켜면 **교체** 화면에 **2중교체** 메뉴가 표시됩니다. |
| **하이라이트 색상** | 교체 화면에서 강조 표시할 교사 행 색상 |
| **데이터 초기화** | 시간표·교체·날짜·설정 등 저장 데이터 전체 삭제 |

## 교체

교체 화면 상단에서 **모드**를 선택하고, 시간표 셀을 클릭하여 교체를 진행합니다. 가능한 경로는 **오른쪽 사이드바**에 표시되며, 경로를 선택한 뒤 실행합니다.

### 보기

- 시간표를 조회만 합니다.
- 교체 작업을 하지 않습니다.

### 교체불가

- 교체할 수 없는 시간을 표시합니다.
- 해당 셀(또는 교사 이름 클릭으로 전체 시간)을 **교체불가**로 지정하면, 이후 교체 탐색 시 그 시간은 제외됩니다.

### 1:1교체

- 두 교사의 수업 시간을 서로 맞바꿉니다.
- 교체 가능한 경로를 사이드바에 표시하고 선택할 수 있습니다.

### 2중교체

- 1:1 교체가 어려울 때, 두 번의 1:1 교체를 연결하여 맞춥니다.
- **시작 > 설정**에서 **2중 교체**를 켜야 메뉴에 표시됩니다.
- 예: 교사 A 월1교시 결강 → A의 다른 시간을 먼저 비운 뒤, B와 맞바꿈
- 교체 가능한 경로를 사이드바에 표시하고 선택할 수 있습니다.

### 순환교체

- 2~5명의 교사가 순환하며 수업을 맞바꿉니다.
- 예: A→B→C→A (A는 B의 시간, B는 C의 시간, C는 A의 시간을 받음)
- 사이드바에서 단계 수(2~5단계)로 경로를 필터링할 수 있습니다.

### 보강

- 수업 교체가 불가능할 때, 해당 시간에 수업이 비어 있는 교사가 보강 수업을 진행하는 방식입니다.
- 결강 셀과 보강할 교사(빈 시간)를 선택한 뒤 실행합니다.

### 툴바 (실행 도구)

| 도구 | 설명 |
| ------ | ------ |
| **원본 / 교체** | OFF: 원본 시간표, ON: 교체 반영된 시간표 표시 |
| **결보강 전체 초기화** | 교체 목록·저장된 날짜를 모두 초기화합니다. |
| **되돌리기 / 다시실행** | 교체 실행 이력을 되돌리거나 다시 적용합니다. |
| **선택 교체 삭제** | 사이드바에서 선택한 교체 경로만 삭제합니다. |
| **줌** | 시간표 확대·축소 |

## 계획서 출력

교체 내역을 바탕으로 결보강 문서를 작성합니다. 왼쪽 메뉴 순서는 **내용 입력 · 결보강 출력** 입니다.

### 내용 입력

- 교체 목록을 표 형식으로 확인하고 **결강일·교체일·보강 과목** 등을 입력합니다.
- **새로고침**: 표 내용을 다시 불러옵니다.
- **날짜과목 초기화**: 입력한 날짜·과목만 지웁니다. (교체 목록은 유지)
- **결보강 초기화**: 교체 목록과 저장된 날짜를 모두 지웁니다.
- **엑셀서식 복사**: 표 내용을 탭으로 구분해 복사합니다. 엑셀에 붙여넣기 할 수 있습니다.

### 결보강 출력

- **양식 1**, **양식 2** 기본 PDF 양식 또는 **직접 만든 PDF 양식**을 선택합니다.
- 결강교사, 결강기간, 학교명 등을 입력한 뒤 **PDF 출력·인쇄**로 저장합니다.
- 사용자 지정 PDF 양식 제작은 **도움말 > PDF 양식 제작**을 참고하세요.

## 안내

교체 정보를 바탕으로 교사·학급 안내 문구를 자동 생성합니다. 왼쪽 메뉴 순서는 **교사안내 · 학급안내** 입니다.

### 교사안내

- 교체 정보를 교사별로 묶어 안내 문구를 자동 생성합니다.
- 형식을 선택한 뒤 **복사**하여 메신저·문서에 붙여 넣습니다.

### 학급안내

- 교체 정보를 학급별로 묶어 안내 문구를 자동 생성합니다.
- 형식을 선택한 뒤 **복사**하여 학급 안내에 사용합니다.

---

## 시간표

- **시작**에 저장한 기본 교사와 **계획서 출력 > 내용 입력**에 등록된 교체·보강 관련 교사의 시간표를 **카드 형태**로 표시합니다.
- 상단 **주차 칩**으로 결보강 날짜가 속한 주를 선택할 수 있습니다.
- **원본 / 교체** 스위치로 교체 반영 여부를 전환합니다. (기본값: 교체 ON)
- **줌**으로 카드 안 시간표 크기를 조절합니다.
- 각 카드 오른쪽 **복사** 버튼으로 해당 교사 시간표 이미지를 클립보드에 복사할 수 있습니다.
- 날짜가 지정되지 않은 교체 항목은 표시되지 않을 수 있습니다. **계획서 출력 > 내용 입력**에서 날짜를 지정하세요.

## 정보

- 프로그램 이름, 버전, 제작자, 라이선스, 연락처 등을 확인합니다.
- 베타·설치판에는 **사용 기한** 안내가 표시될 수 있습니다.
